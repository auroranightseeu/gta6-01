# GTA 6 — open-world crime game (make.fun gta6-01)

An original open-world crime game that plays offline in a desktop browser from its own files: a sun-soaked city to explore on foot and by car, traffic and pedestrians, cars to steal and drive, a wanted level with police who respond, missions and a story, combat, a HUD with a minimap, a start screen and saves.

Built for the make.fun gta6-01 bounty. See game/ for the game, main.ts for the entry program.
